# Музыкальный сайт
Слушайте музыку локально, с плейлистами, статистикой и прочим
## Функции
- Песни взяты локально
- Плейлисты
- Статистика общая и по дням
- Визуаиализатор звука
- Приятный интерфейс
- Изменения информации о песнях, записывается прямо в файлы
# ПРОЕКТ ТЕСТОВЫЙ
Пока что нет класного способо установить т.к. не все функции доделанны, однако можно развернуть проект в ручную)
### ручная утановка
```bash
cd frontend
npm run dev
```
```bash
cd backend
python -m venv .venv
. ./venv/bin/activate
pip install -r requirements.txt

uvicorn main:app --port 8000
```

### 🐋запуск через Docker
Также можно через docker-compose, однако в связи с изменениями он может  выдать ошибку(.
```bash
docker compose up --build --no-cache -d
```
